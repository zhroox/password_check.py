# password_check.py

This is a simple Python program that checks if a password is strong enough. 
It ensures that the password is at least 8 characters long and contains both letters and numbers. 
The user has up to three attempts to enter a valid password before the program ends.

## Features
- Checks password length (minimum 8 characters)
- Checks for the presence of letters and numbers
- Allows up to 3 attempts for the user
- Provides clear feedback for weak passwords
